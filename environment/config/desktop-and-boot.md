# デスクトップ・起動設定の記録

2026-11-01に保存資料を照合して追記。以下は当時の実機確認結果。未適用の追加案は記載しない。

同日に実機から原本を追加採取した。[最新の採取結果](../manifests/current-2026-11-01.md)と[設定原本](observed-2026-11-01/README.md)を優先して参照する。現在の保存済み画面設定は1600×1200・60 Hzで、過去の1920×1200の記録とは区別する。

## 1. デスクトップ関連：実機で確認された状態

2026-08-09の実機調査記録に次が残っている。

|項目|確認された状態|残っていない情報|
|---|---|---|
|デスクトップ|XFCE 4.16とXFCE Goodies導入済み|最初の導入日時・全操作履歴|
|起動|GDMからstartxfce4でXFCEセッションを起動|起動設定・セッション設定の完全な原本|
|ログイン|自動ログイン設定あり|実際の全設定ファイル原本|
|描画|XFCEコンポジター無効|ユーザー設定XML全体|
|画面|1920×1200、60 Hz|モニター情報とユーザー表示設定の全体|

ここで確認できるのはGNOME系の環境からXFCEを利用する構成にしたこと。Xサーバー自体を別の実装へ置き換えた、という事実までは資料から確認できない。GDMを使用していた。

### 元メモに残る設定手順

以下は再構築の参考として残す。導入・無効化の状態は実機記録で裏付けられているが、当時このコマンドを実行した日時・操作経路までは復元できない。

```bash
sudo apt install xfce4 xfce4-goodies
xfconf-query -c xfwm4 -p /general/use_compositing -s false
```

セッション選択の説明も残っている。自動ログイン・GDM・モニター設定を含む完全な再現手順は、実機原本を採取してから確定する。

## 2. 再現のために採取する原本

- GDM・自動ログイン・セッション選択の設定。
- XFCEのコンポジターと画面配置・解像度のユーザー設定。
- ブート設定全体と、swap/sysctl設定。
- 有効化・無効化したサービスと自動起動アプリの設定。
- 起動時間と起動を待たせる処理の測定結果。

今回のPython製採取処理で、上記の多くの原本と構成情報を取得した。AccountsServiceのユーザー設定原本は権限不足で未採取。すべてを再構築・適用して検証したという意味ではない。
