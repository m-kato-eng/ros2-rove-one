# 実機から採取した設定（2026-11-01）

files/以下に、実機の絶対パスに対応する設定原本を保存した。index.jsonには元のパス、パーミッション、所有者ID、リンク先、保存内容のSHA-256、未存在等の状態を記録している。

2026-11-17にライセンスの[確認記録](../../LICENSE_REVIEW.md)と[変更注記](../../THIRD_PARTY_MODIFICATIONS.md)を追加した。GDM・GRUB設定に隣接する `.license` は後から追加した配布注記で、採取原本には含まれない。元の設定102件とindex内のハッシュは変更していない。

## 含む設定

- ブート設定とカーネル引数、fstab、locale、sysctl。
- GDM自動ログインとディスプレイマネージャー選択。
- XFCEのウィンドウ管理・コンポジター・画面・セッション設定。
- Xセッション定義、システムとユーザーの自動起動設定（存在したもの）。
- モジュール読み込み、udev、サービスの設定原本（読めた対象）。
- systemd有効化・マスク等を表す139個のシンボリックリンク情報。

## 再現時の扱い

これは観測スナップショットで、自動適用ツールではない。files/を丸ごと実機へ上書きしない。対応するソフトを導入してから、端末・ユーザー・ディスプレイに適した設定を選択して適用する。Windows上のファイル所有者をそのままLinuxの所有者と解釈しない。

この採取では設定変更をしていない。SSH認証用の鍵、Wi-Fi接続資格情報、認証データベースは収録対象外。基本採取で存在しなかった設定や/dev/nullを指すリンクは、ファイル内容を作り足さずindexで区別した。

AccountsServiceのユーザー設定原本は一般ユーザーから読めず未採取。D-Busで取得したXSession値は空文字だったため、特定のセッションを設定済みと推定しない。

元の採取結果・失敗・再試行データは、Git管理対象外のwork_data/environment/に保持する。
