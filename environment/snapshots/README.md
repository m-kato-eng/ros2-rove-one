## 保持方法

- 新しい採取結果は別の日付・時刻のディレクトリへ追加し、基準として保存した結果を上書きしない。
- 設定・版一覧・採取条件・取得失敗や制限事項を一緒に保持する。
- 秘密情報を確認してから取り込む。SDイメージや日々のアプリ実行ログとは区別する。
- .gitattributesで改行変換を無効化し、採取出力のバイト列とハッシュを保持する。
- 今後の採取時は、使用した採取スクリプトのコミットIDを記録する。今回の採取時はGit未初期化のため、そのIDは未記録。

work_data/environmentは採取直後の作業場所。ここへ取り込んだスナップショットを構成管理用の基準とする。
