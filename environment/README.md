## 再現性の現在地

**実機構成を採取したが、クリーンなSDカードからの再構築は未検証。** 初回OSイメージのファイル名・入手元・ハッシュ、一部の権限制限された原本、配布元の再取得可能性の確認は不足している。ネットワーク認証情報等は意図的に対象外。次は予備SDカードで構築・検証する。

ユーザーはSDイメージを作成・圧縮し、元のimgと展開後imgのハッシュが一致したと報告した。これは圧縮・展開の整合性確認であり、復元・起動の検証とは区別する。

## 今後の運用

1. 現在の構成を採取し、秘密情報が含まれないか確認してmanifestsへ取り込む。
   採取出力自体もsnapshotsへ保存し、整理済み一覧だけでなく基準データを保持する。
2. 変更時はconfig・再構築手順を更新し、変更理由と検証結果をCHANGELOGへ残す。
3. 実機に適用したコミットを記録する。Gitへの保存と実機への適用は別の操作。
4. 節目でSDイメージを保管し、ファイル名・ハッシュ・対応するコミットを記録する。

秘密鍵、パスワード、認証情報を含むネットワーク設定、SDイメージはGitへ入れない。完全に同じ版を再取得できる保証が必要な場合は、配布元のスナップショットや必要なインストーラーも別途保管する。

Git初期化・コミット・GitHub送信はこの作業では実施していない。
