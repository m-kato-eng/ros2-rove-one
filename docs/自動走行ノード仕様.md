# 自動走行ノード

`pi4_motor_control` パッケージに `autonomous_driving` を追加。
`object_recognition` は目標座標の検出に専念し、左右方向の算出は自動走行側で行う。

2026-11-08：Piへ反映する現在の実装は **ライトの明かり（light_spot）追跡版**。
[床の赤色レーザー光点](床の赤色レーザー光点・検出追跡仕様.md)は今後の仕様案として保留する。
画像内の点の追跡は認識側、左右方向・近さ・速度・操舵の判断は本ノードで行う。

## データと制御

- 入力：`/vision/ground_target`（std_msgs/String JSON）。`tracking` かつ `target_valid=true` の `target.target_normalized.x/y`（0〜1）を使用。
- 出力：セッション名前空間の `autonomous/command`（std_msgs/String JSON）。速度、操舵、緊急停止要求、判断理由、相対距離、左右偏差を10 Hzで発行。
- 左右偏差：`2*x-1`。中央±0.1は直進。画像右なら右旋回、画像左なら左旋回。既存のsteer制御を使い、後輪Duty維持・前輪±30%補正を適用。
- 水平線：`horizon_y` パラメーター、初期値0.5（0以上0.75未満）。相対距離 `d=(0.75-y)/(0.75-horizon_y)`。
- 速度目標：`0.04+0.16*d` m/s。水平線位置で0.20、停止境界の手前で約0.04。未校正のため実速度の保証値ではなくモーター制御への指令値。
- `y>=0.75` は緊急停止。モーターノードのラッチを使い、解除しても無効状態のまま。目標が停止領域を離れてから解除・再有効化する。
- Unknown、未検出、不正座標、水平線より上、認識異常、画像の寿命1.5秒超過では速度・操舵を0にする。通常の目標消失停止は新しい有効目標で再開する。
- source_frame.stampで画像自体の古さを確認する。同じ画像の再配信では寿命を延長しない。タイマーと受信後の寿命判定には単調時計を使用。

距離は画像上の相対値（水平線側1、停止境界0）。m単位の距離ではない。実距離にはカメラの高さ・姿勢・内部パラメーターの校正が必要。

## 指令元の選択と停止

`pc_bridge` が専用モーターノードと専用自動走行ノードを起動し、モーターへの指令を一本化する。
初期指令元はmanual。PC画面の「PC手動」「自動走行」で選択する。
切替は停止・無効化を伴い、改めて「有効化」が必要。自動モードでは方向ボタン・一輪操作を無視。
PCの「停止 / 無効化」、Space、Esc、フォーカス喪失、接続切断は自動走行中も有効。
PCからのheartbeatが350 ms途絶すると無効化。自動指令が350 ms途絶した場合や自動ノード終了時も無効化する。
ブリッジ停止時はモーター側500 msのwatchdogが停止させる。

SSH JSON操作に `{"op":"source","value":"manual|auto","id":番号}` を追加。
statusに `command_source` と `autonomous` を追加する。
自動ノードの出力は候補指令であり、モーターへ直接送らない。PCブリッジを通さず起動しただけでは走行しない。

## 起動

Piの作業コピーでビルドする：

```bash
cd ~/ros2-rove-one/ros2_ws
source /opt/ros/humble/setup.bash
colcon build --packages-select pi4_motor_control pi4_camera_vision
source install/setup.bash
```

認識ノードは従来の `camera_vision.launch.py` で起動。PC映像表示の起動経路でも認識を起動する。
PCでSSH接続→「自動走行」→「有効化」。初期設定はdry-run。
モーターと認識は同じROS_DOMAIN_ID（既存PC設定では88）を使用する。
`autonomous_driving` は `/vision/ground_target` を購読するため、認識を別名前空間で起動する場合はROS remapが必要。

## Pi上の統合試験

ビルド後、実車モーターに出力しない専用セッションで実行する：

```bash
cd ~/ros2-rove-one/ros2_ws
source /opt/ros/humble/setup.bash
source install/setup.bash
ROS_DOMAIN_ID=89 python3 src/pi4_motor_control/scripts/validate_autonomous.py
```

合成ライト画像を実際のBrightGroundDetectorへ渡し、ROSで自動ノード・PCブリッジ・dry-runモーターへ接続する。
既存カメラのdomain 88とは分離する。左右操舵、近接減速、Unknown、画像停止、PC停止、手動／自動切替、PC heartbeat途絶、下1/4の緊急停止ラッチを確認する。
`pc_bridge.py --target-topic /任意の目標トピック` で購読先を変更できる。通常は従来の `/vision/ground_target`。
