## PiからL298Nへの信号線

BCM GPIO番号はソフト用、物理ピン番号は40ピンヘッダー上の位置。

|基板|L298N端子|役割|BCM GPIO|Pi物理ピン|
|---|---|---|---|---|
|前輪|IN1|右前輪・方向1|17|11|
|前輪|IN2|右前輪・方向2|18|12|
|前輪|ENA|右前輪・速度PWM|19|35|
|前輪|IN3|左前輪・方向1|4|7|
|前輪|IN4|左前輪・方向2|5|29|
|前輪|ENB|左前輪・速度PWM|6|31|
|後輪|IN1|右後輪・方向1|20|38|
|後輪|IN2|右後輪・方向2|21|40|
|後輪|ENA|右後輪・速度PWM|22|15|
|後輪|IN3|左後輪・方向1|12|32|
|後輪|IN4|左後輪・方向2|13|33|
|後輪|ENB|左後輪・速度PWM|16|36|

共通GND：Piの物理6番を、両ドライバーのGNDと共通にする。必要に応じて分岐端子を使う。モーターの大電流の戻り道はモーター電源へ直接配線し、Piを経由させない。Piの3.3 V/5 V電源ピンは、この信号線の表では使用しない。

## 対応するソフト設定値

現在のmotors.yamlには反映していない。将来、実配線の確認後に使用するBCM設定は次のとおり。配列は基板端子番号そのものではなく、各モーターの方向1・方向2・Enableに対応するGPIO番号。

```yaml
left_front.pins: [4, 5, 6]
left_rear.pins: [12, 13, 16]
right_front.pins: [17, 18, 19]
right_rear.pins: [20, 21, 22]
```

回転方向は未確認。OUT端子のモーター線の極性によって変わるため、初回の低出力試験で必要なモーターのinvertを決める。現行ソフトはdry_run=true / hardware_confirmed=false、ピン未設定のまま保持する。

## 現段階での作業範囲

- 配線時はPiの電源、USB等からの給電、モーター用電池をすべて外す。
- 基板の印字を見てENA/ENBの信号ピンを確認する。外したジャンパーの相手側の5 VピンへGPIOを接続しない。印字やピン列が曖昧なら接続前に拡大写真で確認する。
- 速度制御を使うため、各基板のENA/ENBの短絡キャップは外す。電源レギュレーター設定用のジャンパーは別物であり、現段階ではその設定を変更しない。
- モーター定格・電池の種類・基板の制御用5 V供給方式が未確認なので、電源端子への新規配線と通電は保留。
- 実出力前にはENの外付けプルダウンと物理的な電源遮断方法も確認する。
