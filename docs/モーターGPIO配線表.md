# モーターGPIO配線表

2026-11-01、ユーザーの依頼により以下の信号割り当てを確定。2026-11-02、ユーザーより全輪の回転と前後方向の一致を確認済みとの報告あり。モータードライバーは12 Vで駆動し、問題ないことを確認済みとの報告あり。

## PiからL298Nへの信号線

BCM GPIO番号はソフト用、物理ピン番号は40ピンヘッダー上の位置。

|基板|L298N端子|役割|BCM GPIO|Pi物理ピン|
|---|---|---|---|---|
|前輪|IN1|右前輪・方向1|17|11|
|前輪|IN2|右前輪・方向2|18|12|
|前輪|ENA|右前輪・速度PWM|19|35|
|前輪|IN3|左前輪・方向1|4|7|
|前輪|IN4|左前輪・方向2|5|29|
|前輪|ENB|左前輪・速度PWM|6|31|
|後輪|IN1|右後輪・方向1|20|38|
|後輪|IN2|右後輪・方向2|21|40|
|後輪|ENA|右後輪・速度PWM|22|15|
|後輪|IN3|左後輪・方向1|12|32|
|後輪|IN4|左後輪・方向2|13|33|
|後輪|ENB|左後輪・速度PWM|16|36|

共通GND：Piの物理6番を、両ドライバーのGNDと共通にする。必要に応じて分岐端子を使う。モーターの大電流の戻り道はモーター電源へ直接配線し、Piを経由させない。Piの3.3 V/5 V電源ピンは、この信号線の表では使用しない。

## Raspberry Pi 4 物理ピン1〜40の配置と接続先

下図は40ピンヘッダーの物理ピン番号順。左列が奇数、右列が偶数。`未接続`はこのモーター制御・シャットダウンボタン配線では使わない割り当てを示す。GPIO番号はBCM表記。

|左列（奇数ピン）|右列（偶数ピン）|
|---|---|
|**1** — 3.3 V電源（未接続）|**2** — 5 V電源（予備）|
|**3** — GPIO2 / SDA1（未接続）|**4** — 5 V電源 — ドライバー制御用5 Vの供給元|
|**5** — GPIO3 / SCL1 — シャットダウンボタン|**6** — GND — モータードライバー共通GND|
|**7** — GPIO4 — 前輪 IN3|**8** — GPIO14 / TXD（未接続）|
|**9** — GND — シャットダウンボタン|**10** — GPIO15 / RXD（未接続）|
|**11** — GPIO17 — 前輪 IN1|**12** — GPIO18 — 前輪 IN2|
|**13** — GPIO27（未接続）|**14** — GND（未接続）|
|**15** — GPIO22 — 後輪 ENA|**16** — GPIO23（未接続）|
|**17** — 3.3 V電源（未接続）|**18** — GPIO24（未接続）|
|**19** — GPIO10 / SPI0 MOSI（未接続）|**20** — GND（未接続）|
|**21** — GPIO9 / SPI0 MISO（未接続）|**22** — GPIO25（未接続）|
|**23** — GPIO11 / SPI0 SCLK（未接続）|**24** — GPIO8 / SPI0 CE0（未接続）|
|**25** — GND（未接続）|**26** — GPIO7 / SPI0 CE1（未接続）|
|**27** — GPIO0 / ID_SD（未接続）|**28** — GPIO1 / ID_SC（未接続）|
|**29** — GPIO5 — 前輪 IN4|**30** — GND（未接続）|
|**31** — GPIO6 — 前輪 ENB|**32** — GPIO12 — 後輪 IN3|
|**33** — GPIO13 — 後輪 IN4|**34** — GND（未接続）|
|**35** — GPIO19 — 前輪 ENA|**36** — GPIO16 — 後輪 ENB|
|**37** — GPIO26（未接続）|**38** — GPIO20 — 後輪 IN1|
|**39** — GND（未接続）|**40** — GPIO21 — 後輪 IN2|

シャットダウンボタンは押している間だけ物理5番（GPIO3）と物理9番（GND）を接続する。GPIO3へ5 Vを入れない。Piの物理2番・4番の5 Vは電源レールで、OSのシャットダウンだけでは電圧が切れない。電源を完全に切るにはUSB-C電源を外すか、別途電源スイッチ回路を使う。

## 対応するソフト設定値

motors.yamlにはBCMピン割り当てが反映されているが、dry_run=true / hardware_confirmed=false のため通常設定では実出力しない。配列は基板端子番号そのものではなく、各モーターの方向1・方向2・Enableに対応するGPIO番号。

```yaml
left_front.pins: [4, 5, 6]
left_rear.pins: [12, 13, 16]
right_front.pins: [17, 18, 19]
right_rear.pins: [20, 21, 22]
```

全輪の回転と前後方向はユーザー確認済み（2026-11-02）。現在のinvert設定は全輪false。

## 現段階での作業範囲

- 配線時はPiの電源、USB等からの給電、モーター用電池をすべて外す。
- 基板の印字を見てENA/ENBの信号ピンを確認する。外したジャンパーの相手側の5 VピンへGPIOを接続しない。印字やピン列が曖昧なら接続前に拡大写真で確認する。
- 速度制御を使うため、各基板のENA/ENBの短絡キャップは外す。電源レギュレーター設定用のジャンパーは別物であり、現段階ではその設定を変更しない。
- モーター定格は未確認。実機試験では車輪を浮かせ、低出力・短時間から行う。
- 実出力前にはENの外付けプルダウンと物理的な電源遮断方法も確認する。
